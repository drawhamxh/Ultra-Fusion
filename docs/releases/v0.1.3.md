# Ultra-Fusion ROS1 Noetic v0.1.3

This release is based on v0.1.2 and retains its existing functionality, with
focused improvements for D360/UFO multi-camera replay.

## Highlights

- Improves D360/UFO multi-camera replay stability.
- Hardens synchronization, queues, exception handling, and shutdown.
- Prevents rejected estimates from entering mapping outputs.
- Retains opt-in map PCD export, disabled by default in every shipped profile.
