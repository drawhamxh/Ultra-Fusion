# Ultra-Fusion ROS2 Humble v0.2.2

This release improves the ROS2 Humble estimator runtime and adds opt-in LiDAR
map PCD export.

## Highlights

- Adds the same flag-gated map keyframe and `map.pcd` generation contract as
  ROS1. All shipped ROS2 profiles keep it disabled by default.
- Preserves ROS2 Humble LIO, LWIO, LVWIO, VIO, and VIWO profiles while merging
  the latest ROS1 estimator reliability work.
- Reduces LVWIO memory and copy overhead by moving LiDAR buffers, releasing
  retained visual frames, and compacting sampled-cloud capacity.
- Hardens RGB-D depth-only initialization and invalid inverse-depth handling.
- Makes visual outlier refinement transactional and improves GNSS
  input/configuration and ECEF-anchor handling.
- Adds dedicated packaged Longtime02 LVWIO settings and regression coverage for
  sensor readiness, LiDAR quality, ZUPT behavior, marginalization lifetime,
  multi-camera selection, and runtime memory contracts.

## Map PCD configuration

```yaml
map_pcd:
  enable: false
  output_directory: "/tmp/Ultrafusion"
  translation_threshold_m: 2.0
  rotation_threshold_deg: 30.0
  service_name: "/ultrafusion/generate_map_pcd"
```

With `enable: true`, keyframes are written under
`<output_directory>/keyframes/`. Generate the combined map before stopping the
node:

```bash
ros2 service call /ultrafusion/generate_map_pcd std_srvs/srv/Trigger '{}'
```

The result is `<output_directory>/map.pcd`. No directory, keyframe, or service
is created while the flag is false.

## Validation

- ROS2 build and CTest: 2/2 passed in the Humble environment.
- Final Debian metadata, RUNPATH/SONAME, symlinks, bundled CPU-only Ceres,
  wrapper syntax, and runtime `ldd` checks passed with no unresolved library.
- Rebuilding with the checked-in ROS2 packager in the target Humble runtime
  produced an extracted payload identical to the staged final package.
- Installed-package bag replays covered LiDAR, IMU, wheel, RGB, and depth with
  clean shutdown and no backend solve failures.
- Map export was checked with the flag disabled and enabled. The disabled path
  creates no map artifacts or service; the enabled path saves keyframes and
  generates a consistent combined `map.pcd` through the Trigger service.

`ultrafusion-ros2:0.2.1`; no `0.2.2` Docker tag or digest is claimed here.
